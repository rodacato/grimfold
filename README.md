# Grimfold

A grimdark dungeon crawler for 10-minute gaps. You descend Dante's Inferno one Piso at a time,
and your Personaje, Botín and Historia carry over. It plays on the phone as an offline app, and
on paper with a pencil and two dice, using the same rules.

The art is cut-out collage made from public-domain engravings (Doré, Bosch, Holbein), moved like
puppets.

**Status:** pre-MVP. The product brief is written; nothing is built yet. Spanish only at launch.
