# Grimfold

A sea-horror crawler for 10-minute gaps. You are the lighthouse keeper's daughter: each Marea you
sail out of a foggy bay, fish horrors by fighting them with two dice, steal the Luz from the
Farolero and run home with it, one chapter closer to what happened to your father. It plays on the
phone as an offline app, and on paper with a pencil and two dice, using the same rules.

The art is cut-paper collage, moved like puppets.

**Status:** pre-MVP, building the walking skeleton. Spanish only at launch.
